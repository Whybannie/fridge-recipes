# Холодильник Шеф

MVP-сайт для поиска рецептов по продуктам, которые есть у пользователя.

## Возможности

- выбор продуктов кнопками;
- поиск рецептов по выбранным продуктам;
- показ совпадений и недостающих ингредиентов;
- полностью статический сайт без фото и AI.

## Локальный запуск

```bash
python3 -m http.server 8080
